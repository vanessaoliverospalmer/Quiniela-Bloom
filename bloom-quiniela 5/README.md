# Quiniela Mundial 2026 – Bloom the Coffee

App web completa para la quiniela del Mundial FIFA 2026.

## Cómo publicar en Vercel (gratis, 5 minutos)

### Opción A: Subir directamente (sin código)

1. Ve a https://vercel.com y crea una cuenta gratuita (con tu email o Google)
2. En el dashboard, haz clic en **"Add New Project"**
3. Selecciona **"Deploy a template"** o busca la opción **"Upload"** / drag & drop
4. Arrastra la carpeta `bloom-quiniela` completa
5. Clic en **Deploy** → en 30 segundos tendrás tu URL

### Opción B: Via GitHub (recomendado para actualizaciones fáciles)

1. Crea una cuenta en https://github.com
2. Crea un repositorio nuevo, llámalo `bloom-quiniela`
3. Sube el archivo `index.html`
4. Ve a https://vercel.com → "New Project" → importa desde GitHub
5. Deploy automático. Cada vez que cambies algo en GitHub, se actualiza solo.

### Tu URL será algo como:
`https://bloom-quiniela.vercel.app`

## Panel de administrador

- URL: tu-url.vercel.app (luego clic en "Admin" en la barra superior)
- Contraseña por defecto: **bloom2026**
- Cámbiala desde Admin > Configuración

## Funciones incluidas

- ✅ Registro de participantes (nombre + email)
- ✅ Quiniela completa: fase de grupos (48 partidos), octavos, cuartos, semis
- ✅ Pronóstico de campeón y 3er lugar
- ✅ Sistema de puntos automático (3pts exacto, 1pt ganador)
- ✅ Ranking en tiempo real
- ✅ Panel admin: ingresar resultados reales, marcar pagos, eliminar participantes
- ✅ Cuota configurable desde el panel admin
- ✅ Diseño naranja corporativo Bloom
